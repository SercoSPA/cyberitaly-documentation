Guest User Quickstart🔗

This section is intended for first-time users and guest accounts. If you already have full access to CyberItaly Framework, refer to the other sections of this documentation for a complete overview of the platform’s capabilities.

Viewing Digital Twin Results🔗

If this is your first time logging in, or if you are using a guest account, your access is currently limited to viewing pre-generated results. You will not be able to launch new processing jobs or modify existing datasets — your role is set up to let you explore and consult outputs that have already been prepared for you.

With guest-level access, you have read-only visibility on a set of what-if scenario outputs, generated by specific digital twins. In practice, this means you can browse pre-computed “what if” scenarios.

Where to find them🔗

All of these results are accessible and browsable through CyberItaly Visualization and Analyticsn component.

Here you can: - browse the available what-if scenario outputs on the map - use the built-in visualization and analytics tools to explore each result

For a full walkthrough of the interface (map navigation, layer tools, time navigation, filters, and analytics), please refer to CyberItaly Visualization and Analytics documentation.
