CyberItaly EO Dashboards and Analytics
================

CyberItaly EO Dashboards and Analytics brings together data and processing outputs to support the generation of higher-level insights, combining multiple sources and analyses into coherent, decision-ready information.

Comparing what-if scenarios
----------------------------

CyberItaly EO Dashboards and Analytics allows you to compare **two what-if scenarios of the same
digital twin**, generated using two different sets of forecast data. This
makes it possible to directly assess how differing forecast inputs affect the
resulting scenario, supporting a more informed interpretation of the
digital twin's outputs.
